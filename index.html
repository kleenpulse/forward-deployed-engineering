A free, open course

Forward Deployed Engineering

For software engineers who want an FDE job: the kind where you embed with one customer and ship AI into their real systems. Thirteen lessons of about an hour each, checked against 1,000 real job ads.

How it works

Each lesson teaches one stage of the job, then makes you practise it: quizzes, sorting exercises, writing tasks and small code exercises with instant feedback. No account, no API keys. Your answers save in your own browser. Hover any word with a dotted underline for a plain-English definition.

Syllabus

The stage numbers come from Suraj Sharma's 12-stage FDE roadmap. The course teaches the nine core stages first, in the order the job runs them, then the three specialist ones that only some customers need.

Code exercises

Some lessons include a small exercise you run on your own machine. You need Bun and nothing else: the database exercises use PGlite, a real Postgres that runs inside the script.

Questions, corrections, ideas? Ask in GitHub Discussions, or open an issue or pull request. Every lesson cites its sources. If one is wrong or out of date, say so.
